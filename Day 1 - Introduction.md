# Introduction to Git

## 1. Why Do We Need Version Control?

Imagine editing an image multiple times, saving each version, and sharing it with friends who also make changes. Soon, you may have 40 different versions, making it difficult to track changes or restore an earlier version.

In corporate projects, where multiple people work simultaneously, managing files manually becomes hectic. This creates a need for a **Version Control System (VCS)**.

**Version control** is a system that tracks changes to files over time and allows us to view, manage, and restore previous versions.

## 2. What Is Git?

**Git is a distributed version control system created by Linus Torvalds in 2005.** It helps developers track code changes, maintain project history, and collaborate efficiently.

Without Git, developers might work in a linear fashion, where one person finishes the frontend and passes it to another person for backend development, followed by database integration and deployment. This can waste time.

Git allows multiple developers to work on different parts of a project simultaneously, combine their work, track every recorded change, and revert to earlier versions when needed.

## 3. History of Git

Linus Torvalds developed Git in 2005 out of necessity while working on Linux kernel development. He created it within a couple of weeks, and other contributors continued improving it.

## 4. Git Repositories and Hosting Platforms

A **repository (repo)** stores a project's files and the history of changes tracked by Git. Repositories can be maintained locally and hosted online for collaboration.

Popular Git hosting platforms include:

- **GitHub:** Widely used for hosting repositories and collaborating on open-source projects.
- **GitLab:** Popular for internal company projects and integrated CI/CD workflows.
- **Bitbucket:** Useful for teams that use Atlassian tools such as Jira and Trello.
- **Azure DevOps:** Provides enterprise tools for source control, project management, testing, and deployment.

**Remember:** Git is the version control system, while GitHub, GitLab, Bitbucket, and Azure DevOps are platforms that host repositories and support collaboration.
