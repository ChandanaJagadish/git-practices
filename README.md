# git-practices

# Git & GitHub Learning Journey

A daily log of what I'm learning about Git and GitHub, built in public. Every day I practice one concept, write down what I learned, and commit it, so the commit history itself becomes proof of the journey.

## Why this repo

- Build a consistent daily learning habit
- Practice real Git workflows (commits, branches, merges, pull requests) on a real repo
- Keep a searchable reference of commands and lessons for future me
- Show my progress to recruiters and collaborators

## Learning roadmap

- [ ] Git basics: `init`, `add`, `commit`, `status`, `log`
- [ ] Understanding the working directory, staging area and repository
- [ ] `.gitignore` and tracking changes with `diff`
- [ ] Branching and switching: `branch`, `switch`, `checkout`
- [ ] Merging and resolving conflicts
- [ ] Remotes: `clone`, `push`, `pull`, `fetch`
- [ ] Undoing things: `restore`, `reset`, `revert`
- [ ] Stashing and rebasing
- [ ] GitHub: forks, issues, pull requests, code review
- [ ] Open source contribution workflow
- [ ] GitHub Actions basics
- [ ] Writing a good README and commit messages
